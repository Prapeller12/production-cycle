Инвариант интеграции с Реестром

Производственная вложенность не должна записываться в существующий статусный LINK. Иначе первый входящий этап переведёт основной исходящий проект в «Выполнено». Служебная метка предназначена только для построения дерева производственного цикла.
Оба файла сохраняют штатные заголовки: 9 колонок для исходящих и 8 для входящих, TAB-разделитель, UTF-8 с BOM, CRLF. Существующий импорт сможет прочитать их как документы. Для автоматического восстановления вложенности Реестр должен читать строки этапов в порядке дерева и использовать первую колонку как количество прямых дочерних элементов.
