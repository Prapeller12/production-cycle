# Проверка общей оболочки

Статус до запуска CI: не собрана, Windows-проверки не выполнены.
В ходе работы этот раздел обновляется только по фактическим результатам.

## Автоматическая Windows-проверка

1. Компиляция C++ /W4 /WX, статическая CRT /MT.
2. Два тестовых процесса с system-aware и per-monitor-v2 DPI.
3. Родитель каждого окна — его контейнер; размер соответствует рабочей области.
4. Скрытие первого раздела при выборе второго и сохранение обоих процессов.
5. Повторное открытие первого без перезапуска, изменение размеров, штатное закрытие.
6. Повторение геометрии/переключений на двух реальных бинарных поставках.
7. Снимки экрана обоих разделов и exit code. Снимки нужно оценить визуально:
   один только HWND не доказывает готовность frontend/IPC.

## Обязательная ручная приёмка до использования рабочих данных

Проводить на копиях, отдельно Windows 10 и Windows 11, обычный пользователь,
локальный путь с пробелами и кириллицей, без установленного Python/Node.

- [ ] Запуск с отключённым интернетом и использование только bundled WebView2.
- [ ] Масштаб 100%, 125%, 150%, 200%; перенос между мониторами.
- [ ] Смена раздела сохраняет выделение, прокрутку и ещё не сохранённый ввод.
- [ ] Tab/Enter/стрелки, Ctrl+C/Ctrl+V, русская раскладка, фокус после переключения.
- [ ] Ввод пусто/ноль, сохранение и перезапуск отчётности.
- [ ] Настройки, импорт Excel с предпросмотром, экспорт Excel и PDF отчётности.
- [ ] Создание/открытие/сохранение нескольких проектов с одним номером заказа.
- [ ] Комментарии этапов, справочники и их редактирование, TXT, PDF, Гант.
- [ ] Файловые и печатные диалоги доступны поверх общего окна; отмена работает.
- [ ] Отказ закрытия/несохранённая работа не приводит к принудительному завершению.
- [ ] Повторный запуск фрейма блокируется; независимая копия работает отдельно.
- [ ] Аварийный выход одного модуля, восстановление из backup на копии данных.
- [ ] Собственные `.log` не появляются, данные остаются внутри portable-каталогов.
- [ ] Windows 10: отдельно закрыто ограничение ACL из otchet ADR-0001.

Пока эти пункты не проверены, нельзя утверждать полное соответствие
документации и готовность к производственной эксплуатации.
