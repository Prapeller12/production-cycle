# Разработка самостоятельной программы «Производственный цикл»

Источник требований: прямые указания владельца, docs/architecture-v0.2.md и HTML-макет.
Это самостоятельный проект. Репозиторий Prapeller12/otchet не является целевым remote.

- Поставка: автономный ZIP, Windows 10/11 x64, без установки и администратора.
- Runtime, frontend, config и пользовательские данные — отдельные папки.
- В standalone-режиме данные остаются внутри папки программы. В целевом сетевом режиме
  launcher находится в общей папке, а EXE, Fixed WebView2, профиль и временные файлы
  запускаются только локально; протокол задан в docs/network-share-multiuser-concept.md.
- Целевой сетевой режим не использует собственный процесс на сервере: координация идёт
  через общую папку, максимум три SMB-сессии. Общая SQLite на SMB запрещена.
- Без CDN, телеметрии и собственных технических логов по умолчанию.
- Не обещать отсутствие следов Windows и не удалять системные журналы.
- Сохранять утверждённую компоновку, обязательные поля, дерево, реестр и кнопку PDF.
- Не хранить служебные метки в «Ссылка», не использовать LINK для производственного дерева.
- Не угадывать ручные статусы из TXT. Открытые вопросы фиксировать явно.
- Целевая архитектура: Rust/Tauri, React/Vite, SQLite. Макет не выдавать за production.
- Доменные правила, константы, UI и файловые адаптеры держать отдельно.
- Перед коммитом: node --test tests/domain.test.cjs, git diff --check.
- Перед выпуском: Rust-сборка, браузерные тесты и docs/windows-acceptance.md.
- Не коммитить runtime, рабочую БД, экспорты, профили, секреты и пользовательские файлы.
