# Адаптация frontend по Frontend Reference Kit v1

## Назначение

Документ фиксирует перенос визуального языка эталона «Реестр писем» в приложение «Производственный цикл». Перенос ограничен экранным интерфейсом: бизнес-правила, SQLite, миграции, импорт/экспорт, подписи, резервные копии, native host и печатные шаблоны не изменяются.

Параметры переноса записаны в [frontend-reference-profile.json](frontend-reference-profile.json), осознанные отличия — в [frontend-reference-deviations.json](frontend-reference-deviations.json).

## Что перенесено

| Область | Реализация в приложении |
|---|---|
| Экранная гарнитура | Локальный Golos Text 400/500/700, без CDN и интернета |
| Цвета | Акцент `#e5402b`, тёмный `#1d2029`, фон `#f3f4f7`, белые поверхности |
| Карточки и окна | Радиус 24 px на широком экране, мягкие тени, единая граница |
| Кнопки | 40 px, основная команда 48 px, ясные primary/secondary/danger состояния; действие поясняется локальной пиктограммой и текстом |
| Вкладки | Компактные pill-вкладки, активная вкладка на тёмном фоне |
| Поля | Полупрозрачный фон и нижняя линия, заметный focus и error state |
| Статусы | Приглушённые цветные подложки и текстовая подпись; смысл не зависит только от цвета |
| Таблица и дерево | Спокойные разделители, подсветка строки, отдельный стиль корня и связи |
| Администрирование | Те же токены, но сохранено разделение ролей и опасных действий |
| Узкое представление | Существующая карточная перестройка сохранена и приведена к общему стилю |

## Изоляция печати

Новый файл `frontend/styles/reference-theme.css` содержит только блок `@media screen`. Поэтому он не участвует в формировании:

- производственного отчёта A4 landscape;
- печатной структуры подчинённости A4 landscape;
- диаграммы Ганта A4/A3 landscape.

Печатные формы продолжают использовать `Segoe UI, Arial, sans-serif`. Размер основного текста производственного отчёта и узлов структуры остаётся 14 pt. Эти значения дополнительно защищены регрессионным тестом.

## Неизменённые контракты

- пара TXT: 9 колонок исходящих и 8 колонок входящих;
- локальная SQLite и автоматические миграции;
- несколько проектов с одинаковым номером заказа;
- подписанный журнал «было → стало»;
- три роли ключей и единственный администратор;
- резервные копии и проверка восстановления;
- фильтр выполненных этапов и расчёт процента по полному проекту;
- автономный Windows 10/11 x64 runtime.

## Приёмка

| Проверка | Критерий |
|---|---|
| Автономность | В HTML и теме нет внешних URL; шрифты и пиктограммы находятся в `frontend/assets` |
| Desktop | Реестр, контроль сроков, Гант, диалоги и администратор отображаются без наложений при 1440×1000 |
| Narrow | Основные поля и действия доступны при 760×900, таблица перестраивается в карточки |
| Клавиатура | Сохраняется видимый focus, модальные окна удерживают фокус, вкладки доступны с клавиатуры |
| Пиктограммы | «Ещё», печать, сохранение, импорт/экспорт, открытие и административные команды показывают встроенный SVG рядом с текстом; смысл не передаётся одной иконкой |
| Печать | A4/A3, 14 pt и печатная гарнитура совпадают с предыдущей утверждённой версией |
| Регрессия | Доменный набор Node, Rust tests, native self-test и browser/PDF checks завершаются успешно |

## Сопровождение

Базовые функциональные и печатные стили остаются в `frontend/styles/app.css`. Экранные параметры эталона находятся в `frontend/styles/reference-theme.css`. При дальнейших визуальных изменениях печатные селекторы следует редактировать только по отдельному согласованному требованию.
