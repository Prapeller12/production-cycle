ИСПРАВЛЕНИЯ INTERNET EXPLORER И ОБРАЗЦА EXCEL

В этом комплекте:
• IE11 сам выбирает совместимый интерфейс, даже если сервер открыл обычную страницу.
• «Ещё» открывается и закрывается; поля проекта сохраняют колонки по ширине окна.
• «Скачать образец отчёта» сохраняет встроенный файл .xlsx без запроса к операции сервера.
  Образец и правила импорта не изменены. Доступ есть у всех пользователей.
• Копирование этапов и остальные функции сохранены. Интернет не нужен.

КАК ОБНОВИТЬ ДЕЙСТВУЮЩУЮ ПРОГРАММУ
1. Сотрудники подписывают правки и выходят. Остановите сервер обычным способом:
   «Остановить_программу.cmd»; при работе службой — через «Службы Windows».
2. Сделайте резервную копию всей рабочей папки.
3. Распакуйте новый ZIP во временную папку. Из ProductionCycleServer замените
   в рабочей папке «Производственный_цикл.exe» и всю папку frontend.
   Обновляйте их вместе. Не запускайте второй сервер из временной папки.
4. Запустите прежний EXE или службу. Откройте прежний адрес программы и нажмите Ctrl+F5.

Сохраните ваши config, server-data, tls, server.cer и ярлыки подключения.
Не заменяйте базу и не меняйте сетевые настройки. Инструкции в DOCX сохранены.

ПРОВЕРКА ПОСЛЕ ОБНОВЛЕНИЯ
• В IE11 войдите в свой профиль. Проверьте поля проекта и открытие/закрытие «Ещё».
• «Ещё» → «Скачать образец отчёта»: сохраните .xlsx и откройте его в Excel.
• Если нужна копия этапа: «Реестр цикла» → «Копировать» рядом с «Открыть».

Для первой установки: распакуйте весь ZIP в локальную папку сервера и откройте
«Производственный_цикл.exe». Настройка доступа — по приложенной инструкции.
В корне также лежит готовый ProductionCycle_Excel_import_template.xlsx.
