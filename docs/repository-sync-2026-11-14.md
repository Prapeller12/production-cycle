# Основная ветка и финальная нативная версия

Основная ветка содержит изменения итоговой нативной поставки 13 ноября 2026 года.
Код приложения соответствует `d12e437761752434422eee2965f086c9aaee6cd3`;
выданный EXE построен из `0c7663bf101322dfac8b9abcdd3a3b7b87a09f47`.
Отдельная оболочка `integration/production-frame` и обе истории сохранены.

Код и паспорт перенесены в main через [PR №8](https://github.com/Prapeller12/production-cycle/pull/8)
и [PR №9](https://github.com/Prapeller12/production-cycle/pull/9).
README, правила разработки и автоматическая сборка приведены к текущей архитектуре
через [PR №10](https://github.com/Prapeller12/production-cycle/pull/10).
Принудительная замена main и переписывание истории не применяются.

## Состав текущей версии

В основной ветке находятся накопленные изменения интерфейса и пользователей, поиск
проектов на главном экране, копирование этапов, импорт утверждённого Excel, образец
для всех ролей, подсказки первого входа, печатные исправления и подробная диагностика
сетевого ярлыка. Сохранены подписанный журнал, резервные копии, проверка ревизий,
транспорт снимков через общую папку и предел трёх сеансов.

История перехода на браузерный сервер и возврата к EXE закреплена в
[паспорте](passport/ProductionCycle_Project_Passport_2026-11-14.txt).
Наличие исторических server/IE-файлов не меняет архитектуру действующего выпуска.

Автоматическая проверка основной ветки использует нативный workflow с режимом
local-desktop; автоматическая публикация прежнего portable-прототипа удалена.
Паспорт Word и его текстовая копия находятся в docs/passport. Сведения о проверенном
ZIP, исходниках и контрольной сумме вынесены в [current-release.json](current-release.json).

## Связь с выданным ZIP

`ProductionCycle_FINAL_2026-11-13.zip` остаётся прежним проверенным файлом.
Публикация исходников, документации и настроек CI в main не является его пересборкой.
Код приложения, импортер, тесты и упаковочные скрипты совпадают с финальной рабочей
веткой. В server/Cargo.toml убрана только лишняя пустая строка для git diff --check.

## Проверка

- [Нативная программа и настоящий SMB](https://github.com/Prapeller12/production-cycle/actions/runs/43373470258):
  успешные Windows Server 2022/2025, 39 JS- и 70 Rust-тестов, интерфейс, Excel, семь PDF,
  стандартный пользователь и ярлык.
- [Финальная упаковка](https://github.com/Prapeller12/production-cycle/actions/runs/43393559008):
  обе Windows, воспроизведение старого UNC CMD-отказа, исправленный первый и повторный запуск,
  проверка 603 файлов и неизменности EXE/runtime.
- При синхронизации прошли 39 доменных тестов, git diff --check, проверка YAML и
  сравнение файлов приложения с финальной рабочей веткой.

Запуск на компьютере владельца, Server 2019 и физическом принтере остаётся
эксплуатационной приёмкой. Исходные испытания CI не объявляются такой проверкой.
