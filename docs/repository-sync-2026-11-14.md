## Состав переноса

Перенесены накопленные изменения интерфейса и пользователей, поиск проектов на главном
экране, копирование этапов, импорт утверждённого Excel, образец для всех ролей,
подсказки первого входа, печатные исправления и нативная диагностика сетевого запуска.
Сохранены подписанный журнал, резервные копии, проверка ревизий, транспорт снимков через
общую папку и предел трёх сеансов.

История перехода на браузерный сервер и последующего возврата к EXE закреплена в
[паспорте](ProductionCycle_Project_Passport_2026-11-14.txt).
Наличие исторических server/IE-файлов не меняет выбранную архитектуру текущего выпуска.

Дополнительно обновлены README и AGENTS, добавлены Word и текстовая копия паспорта,
а сведения о проверенном архиве вынесены в [current-release.json](current-release.json).
Автоматическая проверка основной ветки использует нативный workflow с режимом local-desktop;
автоматическая публикация прежнего portable-прототипа из этой ветки удалена.

- [Нативная программа и настоящий SMB](https://github.com/Prapeller12/production-cycle/actions/runs/43373470258):

- [Финальная упаковка](https://github.com/Prapeller12/production-cycle/actions/runs/43393559008):

  файлов приложения с проверенной рабочей веткой.

Новый запуск на компьютере владельца, Server 2019 и физическом принтере остаётся
эксплуатационной приёмкой; исходные испытания CI не объявляются такой проверкой.
