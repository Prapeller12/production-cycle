# Приёмка серверной версии

Объём: отдельная серверная ветка на основе b467eb5. Бизнес-правила, подписи,
миграции и резервное копирование используют исходные Rust-модули; настольные
Tauri-команды исключены только при сборке server. Старые схемы запуска остаются
в своих пакетах. Указания о запуске через SMB не относятся к серверной поставке.

## Обязательные проверки перед выпуском

- 39 существующих JavaScript-проверок данных/контрактов.
- Rust-тесты повторно используемых production/audit/backup и серверных сеансов.
- Реальный HTTPS API: доверие к созданному сертификату, PIN/роли, единственный
  администратор, лимит трёх сеансов, запрос освобождения места администратором,
  подписанные сохранения, отказ устаревшей версии проекта, черновики, резервные
  копии, восстановление и отказ повторного процесса с той же базой.
- API не публикует папки данных/config/tls; отклоняет чужие Origin/Host,
  неподписанную запись и запросы без сеанса. Cookie: HttpOnly и Secure при HTTPS.
- Импорт SQLite без изменения исходника и без перезаписи существующей базы.
- Edge: прежний функциональный сценарий выполняется через настоящий сервер,
  а не через подмену базы или команд. Только финальный отчёт теста и запись
  тестовых экспортов перехватываются стендом.
- Совместимый ES5-пакет: разбор как ES5, функциональный сценарий в Chromium,
  отдельно в настоящем MSHTML/IE11 на Windows. Проверка ES5 в Chromium сама
  по себе не считается доказательством работы Internet Explorer.
- PDF Ганта A4/A3 и подчинённости A4: первая страница содержит отчёт, формат
  и ориентация верны; пустые страницы отсутствуют. Проверяются короткое и
  многостраничное представления.
- Установка, запуск и остановка службы LocalService из распакованной поставки.
- Windows x64 PE: статический CRT и отсутствие импортов vcruntime/msvcp/concrt,
  требующих отдельного Visual C++ Redistributable.
- Подсистема GUI: обычный запуск не создаёт консоль, реально вызывает установленный
  Edge с адресом приложения после готовности. Повторный запуск использует тот же
  процесс/базу; проверяются HTTP и HTTPS, локальный ключ остановки, отказ чужому Origin.
- Нативный клиент готовности проверяет сертификат приложения локально, не отключая
  TLS-проверку. Службу нельзя остановить endpoint-ом ручного запуска.
- Полный функциональный сценарий Edge/ES5 с запретом внешних ресурсов: запросы
  страницы за пределы origin сервера блокируются и считаются ошибкой.
- Комплект сотрудников: только публичный сертификат/адрес/скрипты; без базы и ключей.
  Проверяется открытие HTTPS в Edge с обычной проверкой доверенного сертификата.
- Пакет содержит готовые DOCX и HTML инструкции и все локальные шрифты/скрипты.

Результат определяется последним успешным CI-прогоном именно коммита выпуска
и его артефактами, а не наличием EXE или этим перечнем. Проверки на сервере
пользователя, физических Windows 10/11 и старых Windows/IE требуют отдельной
эксплуатационной приёмки. Совместимость с IE10 и более ранними версиями не заявлена.

## Изменение печати

Удалены именованные страницы на поздних элементах body. Размер бумаги задаётся
одним временным правилом @page для всего печатаемого документа. Экранные элементы,
включая скрытый SVG-спрайт, не участвуют в печатной раскладке. После диалога печати
временное правило удаляется. Данные отчётов, масштаб Ганта и фильтрация не меняются.
