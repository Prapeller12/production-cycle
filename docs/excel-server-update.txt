ПРОИЗВОДСТВЕННЫЙ ЦИКЛ — СЕРВЕРНАЯ ВЕРСИЯ С ИМПОРТОМ EXCEL

ЗАПУСК
Распакуйте ZIP целиком в локальную папку сервера, например C:\ProductionCycle.
Откройте папку ProductionCycleServer и дважды нажмите «Производственный_цикл.exe».
Программа запустит локальный сервер и откроет браузер. Повторное нажатие открывает
тот же сервер. Для проверки на этом компьютере настройка службы не требуется.
Для остановки ручного запуска используйте «Остановить_программу.cmd».

УДАЛЁННЫЙ ДОСТУП И ОБЩАЯ ПАПКА
Если доступ уже настроен, сохраняйте существующие параметры и ярлыки.
При первой настройке запустите «Настроить_сервер.cmd» с правами администратора
и следуйте инструкции ProductionCycle_Setup_Guide.html или .docx в этой папке.
«Создать_папку_запуска.cmd» создаёт папку для сотрудников: из сетевой папки они
открывают «Открыть_производственный_цикл.exe». Подробности находятся в
ProductionCycle_SharedFolder_Guide.html или .docx. Сервер и база остаются в
локальной папке сервера. Для RDP можно запускать основной EXE в сеансе сервера.
Предпочтительно открытие в установленном Edge; запасной вариант — IE11.
Все ресурсы приложения включены в ZIP. Для работы не требуются Интернет,
установка Excel на сервере, Node.js, Rust, загрузка шрифтов или драйвера базы.
Для физической печати используется уже настроенный в Windows принтер.

ОБНОВЛЕНИЕ РАБОТАЮЩЕЙ ПРОГРАММЫ
1. Все сотрудники сохраняют изменения с подписью и закрывают страницы программы.
2. На сервере остановите программу. Если она работает как служба: Win+R,
   services.msc, служба ProductionCycleServer, «Остановить».
   Если запущена вручную: «Остановить_программу.cmd».
3. Скопируйте всю старую папку программы в резервную папку.
4. Распакуйте новый ZIP в отдельную папку. В рабочей папке замените только
   «Производственный_цикл.exe» и всю папку frontend. Скопируйте также новый
   образец ProductionCycle_Excel_import_template.xlsx, VERSION.txt и этот текст.
   ОБЯЗАТЕЛЬНО сохраните прежние config, server-data, tls, server.cer и созданные
   папки/ярлыки подключения. Не подменяйте рабочую конфигурацию пустой из ZIP.
   Нужно обновить И EXE, И frontend — одной замены интерфейса недостаточно.
5. Запустите прежнюю службу либо основной EXE. В открытом браузере нажмите Ctrl+F5.
6. Проверьте вход и список своих проектов. При необходимости возврата остановите
   новую версию и восстановите полную резервную папку из пункта 3.

ИМПОРТ ОДНОГО ПРОЕКТА ИЗ EXCEL
1. «Ещё» → «Скачать образец отчёта». Кнопка доступна всем вошедшим пользователям.
   Такой же файл образца лежит в папке программы.
2. Заполните жёлтые ячейки листов «Проект» и «Этапы». Один файл — один проект.
   Структура согласованного образца сохранена. Звёздочка обозначает обязательное
   поле. Номер заказа с ведущими нулями вводите как текст. Даты — даты Excel
   либо текст ДД.ММ.ГГГГ. Перед импортом замените формулы готовыми значениями.
3. Код этапа должен быть уникальным в файле. Код головного этапа — существующий
   код из этого же файла. Пустая ячейка означает подчинение основному проекту.
   Головной этап может находиться ниже подчинённого. Замкнутые связи запрещены.
4. Сохраните книгу в формате .xlsx. Поддерживается до 5 МиБ и 10 000 этапов.
5. В программе: «Ещё» → «Импорт проекта», выберите файл и проверьте предпросмотр.
   При ошибке исправьте файл и выберите его повторно. В длинном предпросмотре
   видны первые 200 этапов; импортируется всё указанное число этапов.
6. Подтвердите импорт и подпишите сохранение своим PIN и комментарием.
   До успешной подписи данные в базу не записываются. При отмене сохраняется
   текущий проект в рабочем окне. Все импортированные этапы — «Не начато».
   Импорт доступен руководителю проекта, проверяющему и администратору.

ОСТАЛЬНЫЕ ИЗМЕНЕНИЯ
• «Экспорт для Реестра» доступен только вошедшему администратору.
• Строка «поиск проектов» находится на главном экране. Введите запрос и нажмите
  Enter или «Найти»; откроется прокручиваемый список подходящих проектов.
  Поле поиска из окна сохранённых проектов убрано.
• Правила открываются автоматически один раз для каждой учётной записи.
  После установки этой версии первый вход каждой записи покажет правила один
  раз: прежние версии не сохраняли этот признак отдельно на сервере.
  Очистка браузера и другой компьютер не должны повторять показ для этой записи.
• «Ещё» → «Подсказки» открывает правила в любой момент.

ПРОВЕРКИ ПЕРЕД ВЫДАЧЕЙ
Сборка проверяется в Windows Server 2022 и 2025: сервер/API, три роли,
импорт/ошибки/подпись, действительный движок IE11 (MSHTML), Edge, локальные
ресурсы, сохранение и резервные копии, служба LocalService, запуск из общей
папки, диалоги печати и PDF Ганта А3/А4 и подчинённости без пустого первого листа.
Конкретный сервер Windows Server 2019, его сетевые политики и физический принтер
заказчика удалённо не проверялись. Сначала выполните проверку на копии рабочей
папки и базы. При обращении передайте VERSION.txt и текст сообщения об ошибке.
