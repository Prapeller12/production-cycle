# Производственный цикл — история тестовых версий

## Следующая тестовая версия

- Ошибки заполнения этапа теперь показываются внутри открытой формы, выделяют проблемные поля и переводят фокус на первое из них.
- Кнопка формы этапа переименована в «Применить изменения»; отдельно показано, что запись в базу выполняется через подписанное сохранение проекта.
- После выполнения этапа приложение сообщает, что строка скрыта фильтром, и предлагает сразу показать все этапы.
- Массовое завершение основного проекта вынесено в отдельную текстовую опасную команду; удаление, глобальная замена справочника и восстановление базы получили отдельное оформление.
- Верхние команды сгруппированы по разделам «Проект», «Данные», «Отчёты» и «Сервис».
- Общий контроль сроков вынесен в отдельную верхнюю вкладку.
- Административное окно разделено на вкладки журнала, пользователей, проверки целостности и резервных копий; явно показана область журнала — текущий проект или вся база.
- Добавлены семантика модальных окон, управление фокусом, связанные подписи полей, клавиатурная навигация вкладок и озвучиваемые уведомления.
- Увеличены экранные шрифты и элементы управления, усилен контраст; на узком экране реестр перестраивается в карточки без потери полей.
- Гант показывает активный фильтр, количество видимых этапов, текстовые статусы и легенду цветов.
- Исправлено подтверждение выполнения: обычный этап закрывается строго отдельно, отменённая подпись не меняет его статус и не накапливает скрытые завершения.
- Для родительского этапа доступен явный выбор «только выбранный этап» или «вся родительская ветка»; по умолчанию выбран один этап. Основной проект закрывается отдельной командой вместе со всеми этапами.
- Перед подписью показан точный перечень закрываемых этапов, а backend отклоняет несовпадение этого перечня с фактическими изменениями.
- После каждого подписанного сохранения автоматически создаётся и проверяется резервная SQLite-копия; хранятся 10 последних копий.
- Перед миграцией существующей базы и перед восстановлением создаются отдельные страховочные копии.
- В журнале выводится подписанный автоматический список изменённых полей «было → стало».
- Добавлен общий контроль сроков по всем проектам с переходом к конкретному этапу.
- Добавлены регрессионные проверки резервного копирования/восстановления, миграции старой базы, подписанного списка изменений и сводки сроков.
- Исправлена печатная компоновка Ганта: экранная широкая сетка больше не переносится на лист без масштабирования.
- Для печати используются отдельные именованные страницы A4/A3 landscape, фиксированная левая колонка и временная область по ширине листа.
- Шрифт печатной формы закреплён как Segoe UI/Arial; размеры заголовков, этапов и шкалы согласованы между собой.
- Недельные подписи сокращены, а их плотность автоматически уменьшается при печати длинного периода.
- Повторяющаяся подпись «Сегодня» оставлена только в заголовке шкалы; в строках сохраняется красная контрольная линия.
- Возвращена наглядная схема подчинённости проекта; поле можно свернуть и развернуть.
- Диаграмма Ганта получила масштабы «По дням», «По неделям» и «По месяцам».
- Полосы этапов увеличены до 32 px для более наглядного чтения.
- Добавлена отдельная печать Ганта в A4 landscape и A3 landscape.
- Перечень всех сохранённых проектов из SQLite с датой изменения и прогрессом.
- Импорт пары исходящего/входящего TXT с предпросмотром и полной проверкой до замены рабочего поля.
- Экранный фильтр: невыполненные, все или только выполненные этапы.
- PDF не зависит от фильтра и рассчитывает процент по полному набору этапов.
- Отдельная вкладка «Диаграмма Ганта».
- Главный экран очищен от справочных блоков и дублирующей схемы.
- Связь этапа с родителем показана отдельным контрастным маркером.

## Portable-макет №1

Полный ZIP: приложение, отдельные frontend/config и Microsoft Fixed WebView2 x64.
Полностью распакуйте ZIP в локальную папку с правом записи и запустите `production-cycle.exe` из корня папки `ProductionCycle`. Резервный `start.cmd` находится в `app` и для обычного запуска не требуется.

В текущей версии добавлена отдельная печать полной структуры подчинённости проекта. Основной текст печатной формы производственного отчёта увеличен до 14 pt.
Установка Python, Node.js или WebView2 не требуется. Рабочая база SQLite — в data, TXT — в exports.

Это предварительная self-test версия с локальным SQLite-хранением, без интеграции с Реестром.
Проверяется native-запуск на Windows runner GitHub, включая путь с кириллицей и пробелами,
IPC, сохранение JSON/TXT, блокировку исходящей сети EXE/WebView2 и отсутствие Python/Node в PATH.
Windows runner не заменяет приёмку на чистых пользовательских Windows 10/11 x64.

Программа настраивает только права чтения/выполнения AppContainer на папку своего Fixed Runtime;
повышение прав, системные политики, установка и службы не используются.
Полное отсутствие системных следов не гарантируется. Подробности — docs/portable-prototype-1.md.
