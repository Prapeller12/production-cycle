# Производственный цикл — история тестовых версий

## Следующая тестовая версия

- Исправлена печатная компоновка Ганта: экранная широкая сетка больше не переносится на лист без масштабирования.
- Для печати используются отдельные именованные страницы A4/A3 landscape, фиксированная левая колонка и временная область по ширине листа.
- Шрифт печатной формы закреплён как Segoe UI/Arial; размеры заголовков, этапов и шкалы согласованы между собой.
- Недельные подписи сокращены, а их плотность автоматически уменьшается при печати длинного периода.
- Повторяющаяся подпись «Сегодня» оставлена только в заголовке шкалы; в строках сохраняется красная контрольная линия.
- Возвращена наглядная схема подчинённости проекта; поле можно свернуть и развернуть.
- Диаграмма Ганта получила масштабы «По дням», «По неделям» и «По месяцам».
- Полосы этапов увеличены до 32 px для более наглядного чтения.
- Добавлена отдельная печать Ганта в A4 landscape и A3 landscape.
- Перечень всех сохранённых проектов из SQLite с датой изменения и прогрессом.
- Импорт пары исходящего/входящего TXT с предпросмотром и полной проверкой до замены рабочего поля.
- Экранный фильтр: невыполненные, все или только выполненные этапы.
- PDF не зависит от фильтра и рассчитывает процент по полному набору этапов.
- Отдельная вкладка «Диаграмма Ганта».
- Главный экран очищен от справочных блоков и дублирующей схемы.
- Связь этапа с родителем показана отдельным контрастным маркером.

## Portable-макет №1

Полный ZIP: приложение, отдельные frontend/config и Microsoft Fixed WebView2 x64.
Полностью распакуйте ZIP в локальную папку с правом записи и запустите start.cmd.
Установка Python, Node.js или WebView2 не требуется. Рабочие JSON — в data, TXT — в exports.

Это предварительная версия с JSON-хранением, без SQLite и интеграции с Реестром.
Проверяется native-запуск на Windows runner GitHub, включая путь с кириллицей и пробелами,
IPC, сохранение JSON/TXT, блокировку исходящей сети EXE/WebView2 и отсутствие Python/Node в PATH.
Windows runner не заменяет приёмку на чистых пользовательских Windows 10/11 x64.

Программа настраивает только права чтения/выполнения AppContainer на папку своего Fixed Runtime;
повышение прав, системные политики, установка и службы не используются.
Полное отсутствие системных следов не гарантируется. Подробности — docs/portable-prototype-1.md.
