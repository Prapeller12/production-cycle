# Статистика производственного цикла

Откройте «Статистика» рядом с «Диаграмма Ганта». Панель читает сохранённые проекты и журнал через действующий backend. Несохранённые правки текущей карточки в показатели не входят. После подписанного сохранения нажмите «Обновить данные» или повторно откройте вкладку.

«Настроить» позволяет выбрать блоки, их порядок и ширину, оформление, размер шрифта и способ подсчёта. Настройки сохраняются на текущем компьютере отдельно для вошедшего профиля. Их можно перенести через экспорт и импорт JSON. Эти файлы не меняют базу проектов.

## Участие соисполнителей

Выберите заказ в блоке «Участие соисполнителей в заказе». Учитываются все проекты с этим номером заказа. Совпадение UID этапа в разных проектах не объединяет этапы.

- Доля этапов заказа = назначенные исполнителю этапы / все учитываемые этапы заказа × 100%.
- Выполнение своих этапов = завершённые этапы исполнителя / назначенные ему этапы × 100%.
- Например: 3 из 5 этапов дают долю 60%; если завершён 1 из этих 3, выполнение составляет 33,3%.

Расчёт идёт по количеству этапов, без оценки трудоёмкости. По умолчанию учитываются все уровни, как в основной программе; в настройках можно выбрать только конечные этапы. Общий фильтр исполнителя выделяет его строку, сохраняя знаменатель заказа. Другие фильтры ограничивают состав заказа. Округление до одного знака может давать небольшое отклонение суммы отображаемых долей от 100%.

## Файлы и печать

CSV и JSON сохраняются через native IPC в папку exports действующего приложения; полный путь показывается после сохранения. Каждый экспорт получает отдельную папку. CSV содержит UTF-8 BOM для Excel и защиту текстовых значений, начинающихся со знаков формул. Печать вызывает существующий механизм программы; PDF выбирается в системном окне печати.

Загрузка JSON через «Данные» меняет только источник открытой панели. Она не импортирует проекты в рабочую базу. «Обновить данные» возвращает чтение сохранённых проектов программы.

## Ограничения и проверка обновления

Источник читается последовательно. Изменение сводного списка во время чтения прерывает обновление; нажмите «Обновить данные» повторно. Панель не восстанавливает исторические статусы при смене даты расчёта сроков. Проценты не являются долями стоимости или человеко-часов.

Перед обновлением завершите сеансы и сохраните копию старой папки. Распакуйте новый комплект полностью в отдельную папку и перенесите shared целиком, как описано в «КАК ЗАПУСТИТЬ.txt». После входа сверьте один заказ с известным числом этапов и проверьте CSV и печать на своём компьютере. Не заменяйте базу работающей программы.

Состав автоматических проверок: JS-контракты, Rust, настоящее окно Tauri/Fixed WebView2 и SQLite, участие соисполнителей, CSV/JSON, настройки, переход к проекту, PDF, SMB/UNC и запуск через ярлык. Фактические результаты конкретного выпуска закрепляются в docs/current-release.json и GitHub Actions. Проверка CI на Windows Server 2022/2025 не заменяет контрольное открытие на рабочих Windows 10/11 и в вашей сети.
