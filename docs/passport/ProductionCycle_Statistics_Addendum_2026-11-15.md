# Дополнение к паспорту: статистика, 15.11.2026

Базовый паспорт от 14.11.2026 сохранён как историческая фиксация. Это дополнение описывает новый комплект с дашбордами. Точная привязка ZIP к исходникам, размер и SHA256 приведены в [current-release.json](../current-release.json).

## Реализовано

Вкладка «Статистика» находится непосредственно после «Диаграмма Ганта». Сохранены нативная архитектура Rust/Tauri/Fixed WebView2, существующий backend, роли, подписанное сохранение с PIN и комментарием, режим общей папки и лимит трёх сеансов. Миграция схемы базы для дашбордов не нужна.

Девять блоков: участие соисполнителей, предприятия, портфель проектов, ближайшие сроки, обязательства исполнителей, этапы под контролем, состояния этапов, изменения и подтверждения, проверка планов. Состав, порядок, ширина, оформление и размер текста настраиваются; настройки разделены по профилям на текущем компьютере. Поддержаны перенос настроек JSON, выгрузка CSV и печать.

Доля соисполнителя = назначенные ему этапы / этапы выбранного заказа × 100%. Выполнение своих этапов = завершённые / назначенные ему × 100%. Один номер заказа объединяет несколько проектов. Уникальность этапа определяется парой ID проекта и UID. По умолчанию считаются все уровни, доступен режим конечных этапов. Трудоёмкость и стоимость не оцениваются. Правила округления и фильтров изложены в [инструкции](../statistics-dashboard.md).

Панель читает сохранённые проекты; несохранённая карточка в показатели не входит. Используются действующие команды чтения. При выходе из профиля панель очищается, устаревшие ответы отбрасываются. Переход к проекту использует существующую защиту несохранённых изменений. CSV/JSON сохраняются через новый native IPC в exports и не изменяют рабочую базу. JSON в разделе «Данные» меняет только источник панели.

## Проверки и границы

Источник результатов: [полный прогон CI](https://github.com/Prapeller12/production-cycle/actions/runs/43686377639), [изменения PR №12](https://github.com/Prapeller12/production-cycle/pull/12). Сборка выполнена из `52f80c912ff803922f80bc4e7048a37f7a18f889`, голова проверенной ветки — `5ea612a1785b202cc9f7bd0e4290cde064aea185`.

На Windows Server 2022 и 2025 пройдены 61 JS- и 71 Rust-тест, запуск EXE, диагностика, реальное окно Tauri/WebView2/SQLite, Excel, 63 статические кнопки и 14 динамических элементов, 19 сценариев основной проверки и отдельная проверка статистики. Восемь печатных форматов проверены на отсутствие пустых страниц; для прежних отчётов сохранены проверки дат, кегля, границ и наложения слов. Пройдены SMB/UNC, ярлык, обычный пользователь, сеансы, сохранение, восстановление и вспомогательный CMD. На Windows Server 2022 также проверен локальный запуск при блокировке исходящих соединений приложения и runtime.

Панель читает источник последовательно и не объявляет его атомарным снимком. При изменении сводного списка во время чтения требуется повторное обновление. Выбор даты не восстанавливает исторические статусы. Чистые Windows 10/11, Server 2019 владельца, его сеть и физический принтер в этом прогоне не проверялись. Для ввода в работу нужны резервная копия, контрольное открытие и сверка одного известного заказа.
