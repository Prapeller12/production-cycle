# Управление пользователями

Администратор может изменить ФИО профиля, перевести сотрудника между ролями «Руководитель проекта» и «Проверяющий», закрыть или снова разрешить вход и подпись. Единственного администратора нельзя заблокировать или перевести в другую роль.

PIN пользователя не показывается, не выгружается и не записывается в журнал управления. Изменение профиля сохраняет его персональный PIN, ключ подписи и личный экран статистики. Функций просмотра или сброса PIN в этом разделе нет.

## Изменить профиль

1. Нажмите «Администратор» вверху окна.
2. Введите свой PIN администратора и нажмите «Войти».
3. Откройте «Пользователи и ключи».
4. Найдите нужное ФИО и нажмите «Изменить» в его строке.
5. Исправьте ФИО или выберите роль. Галочка «Разрешить вход и подпись» управляет доступом этого профиля.
6. В поле «Причина изменения» укажите основание, например: «Назначен проверяющим по распоряжению № 15».
7. Введите **PIN администратора**, затем нажмите «Сохранить изменения». PIN сотрудника для этого не нужен.
8. Дождитесь сообщения об успешной записи. Если показана ошибка, проверьте её текст: изменение не следует считать подтверждённым.

Операция подписывается администратором. В отдельном журнале сохраняются прежнее и новое ФИО, роль, разрешение входа, причина, дата и автор изменения. Создаётся автоматическая резервная копия. Если профиль записан, но копию создать не удалось, программа сообщает об этом отдельно.

Если профиль уже изменён в другом окне или на другом компьютере, устаревшая форма не перезаписывает его. Обновите список и откройте профиль заново.

Изменение ФИО меняет имя профиля. Текстовые наименования исполнителей в сохранённых проектах автоматически не заменяются: для общей замены используется раздел «Справочники». Прежние подписи и имена в подписанных событиях сохраняются.

Отключённый профиль нельзя использовать для нового входа и подтверждения изменений. Уже открытые данные не удаляются с компьютера другого сотрудника. Удаление профиля не предусмотрено: история и подписи остаются связанными с ним. После повторного разрешения входа сотрудник использует прежний PIN.

Права подписи проверяются по текущей роли в базе. Если в старом сеансе ещё видна прежняя надпись роли или ФИО, повторный вход обновляет её. Эта надпись не даёт прежних полномочий.

## Посмотреть статистику сотрудника

1. Войдите через «Администратор» и откройте «Пользователи и ключи».
2. Нажмите «Статистика» в строке нужного профиля.
3. При необходимости задайте «С даты» и «По дату». Обе даты включаются в период. Пустые даты означают весь доступный период.
4. Введите свой PIN администратора и нажмите «Показать статистику».
5. Для следующей страницы записей используйте «Следующие», для возврата — «Предыдущие». На странице до 50 записей; показатели сверху учитывают весь выбранный период.
6. «Весь период» очищает ограничение дат и загружает все доступные даты. «Закрыть» убирает форму и введённый PIN администратора.

| Показатель | Что считается |
| --- | --- |
| Записей производственного журнала | Записи, подписанные этим профилем в выбранном периоде |
| Сохранений проектов | Подписанные создания, изменения и сохранения проектов |
| Подтверждений выполнения | Подписанные подтверждения выполнения этапов; повторное подтверждение после возврата в работу является отдельной записью |
| Проектов с действиями | Разные сохранённые проекты, в журнале которых есть записи этого пользователя |
| Последняя запись | Время последней зарегистрированной записи пользователя в выбранном периоде |

Таблица показывает дату, вид события, заказ, проект, комментарий и имя подписавшего на момент события. Под ней находятся последние 20 подписанных изменений **этого профиля**, выполненных администратором.

Статистика связывается с постоянным ID пользователя. Поэтому смена ФИО или роли не обнуляет историю. Время событий показывается с сохранённым часовым смещением; ограничение дат использует дату самой записи журнала.

Эти показатели не означают число назначенных работ, отработанные часы, время присутствия или производительность сотрудника. Входы в программу и создание профилей в производственный журнал не включаются. Исполнитель этапа в карточке и человек, подписавший изменение, могут различаться. Доли назначенных этапов смотрите в основном разделе «Статистика».

Если данные не загрузились, программа показывает ошибку. После изменения дат нажмите «Показать статистику» заново. При уходе из раздела введённые административные данные очищаются; запоздалый ответ не должен появляться в другом сеансе.

## Проверка истории

Откройте «Проверка целостности», укажите администратора и его PIN и выполните проверку. Она проверяет производственные подписи и подписанный журнал управления пользователями. При обнаруженном повреждении новые изменения профилей блокируются до проверки и восстановления корректной копии.

Роли и подписи программы действуют вместе с доступом к общей папке Windows. Порядок переноса всей папки shared и резервного копирования остаётся прежним.
