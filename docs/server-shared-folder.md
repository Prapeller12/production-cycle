# Производственный цикл запуск из общей папки

Это отдельный вариант входа в ту же серверную программу. Серверный EXE,
SQLite и весь интерфейс взяты без изменений из проверенной версии b7dbce3.
Прежний ZIP для локального открытия и выдачи комплектов сотрудникам остаётся доступен.

1. Распакуйте этот ZIP на **локальный диск сервера**, в постоянную папку.
2. При переносе проектов сначала выполните `Перенести_старую_базу.cmd`.
3. Откройте `Настроить_сервер.cmd` и настройте сервер по основной инструкции.
4. На том же сервере откройте **Создать_папку_запуска.cmd**.
   Выберите уже доступную сотрудникам общую папку. Мастер создаст в ней
   отдельную папку **Производственный цикл** с кнопкой открытия.
5. Сотрудник открывает эту общую папку со своего ПК и нажимает
   **Открыть_производственный_цикл.exe**. В первый раз он сверяет SHA256
   сертификата с администратором по отдельному каналу и подтверждает подключение.
   Windows может дополнительно запросить подтверждение установки сертификата:
   его SHA1 должен совпасть с показанным в первом окне. Следующие открытия
   для того же пользователя Windows не требуют этого шага,
   пока не изменится сертификат. Открывается отдельное окно установленного Edge,
   при отсутствии Edge — установленный IE11.

В общую папку попадают только клиентская кнопка, открытые настройки и публичный
сертификат. Серверную папку, базу и закрытый ключ туда не копируют. Сотрудникам
достаточно прав чтения и запуска. Папку запуска целиком держат вместе;
подготовщик не настраивает SMB-права и не создаёт новые сетевые ресурсы.

Доступ к файлам общей папки сам по себе не подтверждает доступ к HTTPS TCP 8443.
Этот сетевой доступ настраивает ИТ. RDP для открытия на собственном ПК не требуется.
Интернет не требуется. Windows x64, Windows PowerShell 5.1, встроенный в него
.NET Framework и Edge либо IE11 должны уже присутствовать. Приложение ничего
не скачивает. Шрифты, значки и все скрипты находятся в серверном ZIP.

Не запускайте на одном сервере оба комплекта как две независимые службы с разными
базами. Выберите один комплект. Если b7dbce3 уже настроена в постоянной папке,
сохраните резервную копию и добавьте из нового ZIP только `scripts/server/SharedFolder.ps1`,
`Open-SharedFolder.ps1`, `Export-SharedFolder.ps1`, `SharedFolderLauncher.exe`,
корневую кнопку `Создать_папку_запуска.cmd` и новую инструкцию. Сервер останавливать
или повторно настраивать в этом случае не требуется; действующие данные и TLS
не заменяются. Затем создайте папку запуска.

После смены адреса или сертификата повторите создание папки запуска в том же месте.
Сотрудники подтвердят новый сертификат при следующем открытии.

Пошаговая краткая инструкция: `ProductionCycle_SharedFolder_Guide.docx` и HTML.
Основная инструкция по серверу, резервным копиям и переносу базы:
`ProductionCycle_Setup_Guide.docx` и HTML.

## Проверка

Для новой кнопки предусмотрены Windows-проверки через реальную SMB-папку с правами
только на чтение: отказ и согласие при первом подключении, повторный щелчок,
обычная проверка HTTPS, загрузка интерфейса в Edge без внешних ресурсов,
ошибка несовпадения сертификата и недоступного сервера. Они дополняют уже
пройденные проверки серверного EXE, IE11, подписей, резервных копий и печати b7dbce3.
Проверку корпоративной сети владельца выполняют отдельно с ПК сотрудника.
