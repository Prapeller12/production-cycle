# Результаты проверки нескольких проектов одного заказа — 10.09.2026

## Проверяемые изменения

- удаление уникальности номера заказа в SQLite;
- отдельный внутренний ID для каждой записи проекта;
- создание нескольких проектов с одинаковым номером заказа;
- повторное сохранение открытого проекта строго по его внутреннему ID;
- сохранение экспортных ID этапов в формате `<номер заказа>-<seq>`;
- выбор конкретного проекта по номеру и названию в окне «Сохранённые проекты»;
- поиск в списке по номеру заказа, названию и предприятию;
- миграция существующей базы с уникальным `order_no` без потери старого проекта;
- отсутствие внутреннего SQLite ID в переносимом JSON;
- неизменность TXT 9/8 колонок, PDF, диаграммы Ганта и структуры подчинённости.
