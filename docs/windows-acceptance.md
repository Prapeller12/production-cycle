# Приёмка portable-сборки

Статус: НЕ ПРОВЕДЕНА. Наличие Windows EXE или успешная компиляция не являются этой приёмкой.

Для каждой проверяемой ОС зафиксировать точную версию Windows, архитектуру CPU,
версию/источник/SHA-256 Fixed WebView2 и SHA-256 ZIP.

| Проверка | Windows 10 x64 | Windows 11 x64 |
|---|---|---|
| Чистая ОС, без Python/Node и системного WebView2 | не проверено | не проверено |
| Запуск offline, без администратора | не проверено | не проверено |
| Путь с кириллицей и пробелами | не проверено | не проверено |
| Папка без прав записи: понятный отказ | не проверено | не проверено |
| Масштаб 100/125/150%, 1366×768 и 1920×1080 | не проверено | не проверено |
| Создать проект, дерево и сохранить JSON | не проверено | не проверено |
| Перезапуск и открытие JSON со статусами | не проверено | не проверено |
| Повреждённый JSON не меняет рабочие данные | не проверено | не проверено |
| TXT BOM/TAB/CRLF, 9/8 колонок, пустая ссылка | не проверено | не проверено |
| PDF A4 landscape, многостраничное дерево | не проверено | не проверено |
| Аварийное завершение во время сохранения | не проверено | не проверено |
| Файловые записи приложения внутри папки программы | не проверено | не проверено |
| Нет собственных .log и запросов приложения в сеть | не проверено | не проверено |

Следы контролировать наблюдением за процессом и дочерними WebView2-процессами, не удалением журналов.
Обнаруженные обращения ОС/Defender/печати учитывать отдельно и описывать фактически.
Для выбранной версии Fixed Runtime проверить официальные требования Microsoft к доступу AppContainer
на Windows 10. Скрипт упаковки не изменяет системные политики или ACL пользовательской машины.
