ПРОИЗВОДСТВЕННЫЙ ЦИКЛ — ЛОКАЛЬНАЯ ВЕРСИЯ

ЗАПУСК
1. Распакуйте ZIP целиком в обычную папку на локальном диске, например C:\ProductionCycle.
2. Откройте production-cycle.exe двойным нажатием. Администратор, интернет, установленный Edge и серверная служба для работы не нужны.
3. При первом запуске создайте администратора: ФИО и собственный PIN. Затем создайте рабочие профили в «Пользователи».
4. При следующих запусках выберите свой профиль и введите PIN. Каждый сотрудник работает под своим профилем внутри программы.

Для ярлыка нажмите правой кнопкой на production-cycle.exe → «Создать ярлык». Не перемещайте EXE отдельно от остальных папок.
Закрытие рабочего окна завершает программу. Консоль и служба не запускаются.

ВАЖНО ПРО РАСПОЛОЖЕНИЕ
Рабочая папка программы должна быть на локальном диске и доступна вашему Windows-пользователю для записи. Не запускайте этот комплект из сетевой папки, архива или Program Files.
Данные находятся в data, резервные копии — в data\backups, выгруженные файлы — в exports. Runtime и интерфейс уже в комплекте. Не удаляйте runtime и frontend.
Это локальная база одной папки. Копии программы на разных компьютерах содержат отдельные базы; сетевую совместную работу этот комплект не обеспечивает.
При работе через уже настроенный RDP программу запускают на локальном диске того компьютера, к которому подключились. Общая сетевая папка сама по себе не предоставляет RDP-доступ.

ПЕРЕНОС ДАННЫХ ИЗ СЕРВЕРНОЙ ИЛИ ПРЕЖНЕЙ ЛОКАЛЬНОЙ ВЕРСИИ
1. В прежней программе откройте «Администратор» → «Резервные копии» и создайте ручную копию по PIN администратора.
2. Закройте новую локальную программу. Используйте отдельную свежераспакованную папку, в которой ещё нет рабочей базы.
3. Скопируйте созданный файл резервной копии .db в папку data нового комплекта и назовите production-cycle.db.
4. Откройте новый EXE. Проверьте проекты, пользователей и журнал подписей. Используйте прежние PIN.
5. Сохраните старый комплект и исходную резервную копию до завершения проверки. Не заменяйте базу при запущенной программе. Не переносите только JSON, если нужны пользователи и подписи.
Не копируйте из серверного комплекта EXE, config, frontend или runtime в новую сборку.

ПРОЕКТЫ И ПОИСК
Заполните карточку проекта. «Подписать и сохранить» записывает проект в локальную базу; выберите пользователя, укажите PIN и комментарий.
Строка «поиск проектов» находится на главном экране. Введите название, номер заказа или предприятие и нажмите «Найти». Окно сохранённых проектов содержит прокручиваемый список.
У одного заказа может быть несколько проектов. Выбирайте нужный проект в списке.

ЭТАПЫ И КОПИРОВАНИЕ
«Создать этап» добавляет этап. В поле «Головной этап / основной проект» задаётся подчинённость.
Для однотипного этапа нажмите «Копировать» в строке исходного этапа. Поля будут заполнены, ID создастся новый, статус станет «Не начато». Измените даты и название, сохраните этап и подпишите сохранение проекта.
Подчинённые этапы и документ о выполнении не копируются. Копировать можно также выполненный этап: найдите его через «Показать» → «Все этапы» или «Только выполненные».
Выполненный этап по умолчанию скрыт из рабочего списка, но остаётся в отчётах и общем проценте выполнения.
Для завершения укажите реквизиты существующего документа. Возвращать выполненный этап в работу может только администратор.

ИМПОРТ И ОБРАЗЕЦ EXCEL
«Ещё» → «Скачать образец отчёта» сохраняет .xlsx в папку exports. Путь появляется в сообщении программы. Образец также приложен в папке samples.
Заполните листы «Проект» и «Этапы» по образцу. Сохраните обычный .xlsx без макросов, внешних ссылок и формул. Excel нужен только для редактирования таблицы; сама программа читает её встроенным модулем.
«Ещё» → «Импорт проекта» → выберите .xlsx → проверьте предпросмотр → подтвердите импорт. Затем подпишите сохранение проекта. Импорт не подтверждает выполнение этапов и не создаёт подписи за сотрудников.
Образец доступен всем пользователям. «Экспорт для Реестра» доступен только администратору.

ПЕЧАТЬ
Отчёт проекта: «Ещё» → «Печать отчёта / PDF».
Подчинённость: «Печать структуры».
Диаграмма Ганта: откройте вкладку, выберите масштаб и нажмите «Печать А3» или «Печать А4».
В диалоге печати проверьте бумагу и ориентацию. Для файла выберите доступный на компьютере PDF-принтер. Для физического принтера его драйвер должен быть уже установлен в Windows.
Первый лист не должен быть пустым. Даты, статусы и длинные подписи переносятся внутри своих ячеек. Старый Internet Explorer не участвует в отображении и печати этой локальной версии.

ПОЛЬЗОВАТЕЛИ И ПОДСКАЗКИ
Сотрудник использует собственный профиль и PIN. Действующие пользователи могут создавать рабочие профили с подтверждением PIN. Администратор в программе один.
Административный раздел защищён отдельным подтверждением PIN; там находятся журнал, проверка подписей, справочники и резервные копии.
Правила показываются при первом входе каждого профиля. Повторно открыть их можно через «Ещё» → «Подсказки».
«Выйти из сеанса» позволяет сменить профиль без закрытия программы. Автоматический черновик в data\drafts не заменяет подписанное сохранение.

ОБНОВЛЕНИЕ И РЕЗЕРВНЫЕ КОПИИ
Перед обновлением создайте ручную копию базы. Закройте программу. Распакуйте новую версию отдельно и перенесите базу способом выше. Сохраняйте резервную копию вне рабочего диска.
Если программа не открывается, проверьте полную распаковку и возможность записи в папку. Передайте снимок сообщения об ошибке вместе с названием версии. Не удаляйте базу ради повторного запуска.
