# ADR-0001: отдельный первый макет производственного цикла

Дата: 2026-09-08. Статус: ACCEPTED в пределах поручения создать первый макет по приложенным HTML и документации.

Основание: прямое указание пользователя и architecture-v0.2.md, разделы 4, 12, 25, 26.
Самостоятельный репозиторий production-cycle относится к новой утилите.
Уточнение пользователя: отдельный репозиторий в профиле Prapeller12; otchet не использовать для публикации.
История и код отчётности не включаются в новый Git-проект.
Целевой стек новой утилиты — Tauri/Rust/SQLite. Первый макет сохраняет DOM-компоновку HTML v8;
перенос в React и production-сервисы Rust выполняется следующим этапом, после проверки макета.

Первый макет: доменные правила тестируются отдельно от DOM; рабочий JSON хранит ручные статусы.
Tauri host предоставляет локальную запись файлов и печать, без серверов и системного браузера.
В браузерном просмотре доступна выгрузка файлов стандартными средствами браузера.
Браузерный просмотр не является автономной Windows-поставкой и не удовлетворяет контролю расположения профиля.

Открыто: раздел 31 архитектуры требует отдельного решения о переносе статусов при интеграции.
Первый макет не решает этот вопрос, не применяет TXT в Реестр, не создаёт SQLite или LINK.
Production SQLite и backend-расчёты остаются следующей стадией, а не объявляются реализованными.

Расхождения с v8: ошибочный JSON не заменяет проект; неизвестные статусы, циклы и дубли отклоняются;
счётчик seq проверяется; демо требует подтверждения замены; вкладки реагируют на клавиатуру;
в PDF явно отображается просрочка самого проекта и приостановленных этапов.
Визуальные поля и основной порядок блоков сохранены.

Риск: первый макет не прошёл приёмку на Windows 10/11. Проверка Rust в CI не заменяет запуск GUI.
Откат: удалить отдельный каталог/ветку. Схема БД основной программы не меняется.
