# ADR 0002: локальный клиент и файловая координация через общую папку

Дата: 2026-10-05

Статус: принято; тестовая реализация подготовлена в отдельной ветке.

## Контекст

Пользователи должны открывать программу с разных Windows 10/11 компьютеров через общую
папку. Одновременно работают не более трёх компьютеров. Размещать собственный исполняемый
серверный процесс на файловом сервере нельзя. Ранее использованный Fixed WebView2 не может
работать непосредственно с сетевого пути, а общая SQLite на SMB не является допустимой
рабочей базой.

## Решение

- Сетевая папка используется для распространения launcher/пакета и общего файлового
  хранилища.
- Launcher копирует комплект фиксированной версии и запускает клиент из локального кэша.
- Fixed WebView2 и его профиль всегда локальные.
- Три активные сессии ограничиваются удерживаемыми SMB file handles.
- Приоритетный вход администратора кооперативно вытесняет последнего вошедшего обычного
  пользователя только после сохранения черновика и освобождения слота.
- Автосохранение пишет черновики. Официальная версия меняется только после существующей
  процедуры подписи и обязательного комментария.
- SQLite никогда не открывается непосредственно на SMB. Под единой файловой блокировкой
  общий целостный снимок копируется в локальную SQLite, а запись публикуется обратно полным
  проверенным файлом через временное имя и атомарную замену. Подписанный журнал сохраняется
  внутри снимка.

## Последствия

Основной интерфейс и бизнес-правила сохраняются. Появляются launcher, экран подключения,
состояние сессии и автосохранение черновика. Экран восстановления аварийного черновика и
проектные ревизии остаются условием перед промышленной эксплуатацией.

Файловый режим обнаруживает вмешательство с помощью подписей, но не может запретить прямое
изменение данных пользователю с правом записи. Принудительно завершить зависший удалённый
клиент без серверного координатора невозможно; новый вход ждёт фактического освобождения
SMB handle.

Подробный протокол описан в `docs/network-share-multiuser-concept.md`.
